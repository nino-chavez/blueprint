# research/proposed-changes/

> Forward-looking spec. **What we want to build.** Distinct from `current-state/`
> which catalogues what exists today.

## What goes here

- BRD / PRD source files (if not at repo root)
- Strategy proposals describing target state
- Spec proposals for new capabilities
- Roadmap docs for sequenced delivery

## What does NOT go here

- Current capability inventory → `../current-state/`
- Risk + impact assessment for the changes → `../impact-analysis/`
- Outstanding questions blocking the changes → `../open-questions/tracking.md`

## Cross-references

If the initiative uses BRD at the repo root (e.g., `BRD.md` for full-repo specs),
reference it from here rather than duplicating. The point of this folder is to
provide a single place for "where do the forward-looking specs live" — not to
host them all directly.
