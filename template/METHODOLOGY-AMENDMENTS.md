# Methodology Amendments — This Initiative

This file captures methodology-level learnings specific to this initiative. Append at the top; supersede via new entry; never rewrite history. Full convention: `~/Workspace/dev/wip/blueprint/template/docs/methodology/methodology-amendments-convention.md`.

If you are the operator on a fresh Blueprint initiative, this file starts empty. Add an entry when:

- You notice a methodology gap your initiative had to work around
- You add a hook, reviewer, or doc the methodology doesn't supply
- You skip a stage and want to justify it durably (so a future session reading this doesn't repeat the question)
- You discover something that might be useful to other initiatives — scope it "Candidate for methodology promotion" so the methodology operator can grep for it

Entry shape:

```markdown
## YYYY-MM-DD — Short title

**Trigger**: One sentence
**Scope**: Per-initiative | Candidate for methodology promotion | Promoted to methodology
**Status**: Active | Superseded by YYYY-MM-DD | Promoted

Body — what the amendment is, why, what it changes.

**References**:
- commit / PR / session transcript
```
