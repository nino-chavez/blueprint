# Steering-layer experiment results

## Result

The pre-registered fixture-scale experiment passed. A deterministic layer above
Blueprint's semantic kernel selected the expected next bounded recipe, kept
human encounters behind machine-checkable prerequisites, detected repeated
incidents across revisions, enforced an operator-touch budget, and projected
active claims without deleting history.

This validates the proposed controls as a root research prototype. It does not
validate them as a public Blueprint feature or as a complete steering method.
Only the Blueprint self-dogfood build was prospective. Film Room, Fleet
Observability, and BC Subscriptions were frozen read-only packets derived from
already-known evidence.

## Execution order

1. `00-preregistration.md`, the five valid packets, four invalid packets, and
   their expected results were frozen in commit `5ce3f0e` before the evaluator
   existed.
2. The initial self-dogfood packet selected `implement-or-verify`, so no human
   encounter or methodology-creator interpretation was requested.
3. The dependency-free evaluator and generated JSON/Markdown views were
   implemented inside this directory.
4. A code audit found one readiness edge case before disposition: an authored
   human dependency omitted from the displayed journey could be missed. The
   evaluator was tightened to combine ordered prior steps with the claim's
   declared dependencies, and the adversarial suite proves the correction.
5. The complete self-dogfood packet selected `record-disposition`. This file
   and the root recommendation record that disposition without asserting
   public readiness.

No deferred Film Room operator feedback and no later Film Room candidate were
used to change the frozen packets or expected results.

## Adversarial and mechanical evidence

`test-steering.mjs` passes 74 assertions:

- all five valid packets match their recipes and secondary expectations;
- duplicate claim identifiers, unknown dependencies, unknown journeys, and a
  negative touch budget are rejected with source-line diagnostics;
- a direct human dependency omitted from the displayed journey still blocks
  readiness;
- a completed holistic-audit disposition closes the incident cluster and
  reveals the next contradicted prerequisite;
- both within-budget encounter and exhausted-budget disposition paths are
  exercised;
- stale human evidence, unobservable machine evidence, invalidation, and
  unusual unresolved states cannot fall through to a false `hold`;
- absolute user paths are rejected;
- evaluator source contains no Film Room, Fleet, BC, Claude, or Codex rule;
- JSON is byte-deterministic across repeated evaluation and deleted-output
  rebuild; and
- generated outputs mark themselves as derived and contain no absolute user
  path.

The evaluator requires only Node's standard library. It issues no receipts,
changes no claim, spends no operator attention, and mutates no consumer.

## Limits

The experiment does not establish:

- that cold consumer authors can create the packet without hidden creator
  knowledge;
- that the recipes improve a live external initiative prospectively;
- that the active/history projection remains legible at real longitudinal
  scale;
- that an operator-touch budget is acceptable in practice;
- that support, upgrade, rollback, and compatibility behavior are ready; or
- that Blueprint alone supplies product strategy, design judgment, or
  execution skill.

It also does not convert retrospective Film Room steering work into Blueprint
evidence. The prototype correctly identifies the missing journey-level audit;
it did not perform or cause that audit.

## Disposition

Retain the semantic kernel and retain this steering layer as root-only
experimental research.

Do not change `template/`, public CLI behavior, methodology defaults, or a
consumer from this result. A later public opt-in proposal requires a separately
authorized prospective external pilot whose packet is authored before work,
whose operator-touch budget is enforced during the initiative, and whose
support and rollback behavior are observed. Until then, Blueprint is validated
as an evidence-steered initiative protocol with a promising recipe prototype,
not as a fully validated end-to-end steering method.
