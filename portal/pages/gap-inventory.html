Stage 1 — Diagnose

Nine gaps blocking production quality

Each gap maps to a named pattern from primary sources (Lopopolo, Appleton, Backstage, Shape Up, ai-hive). Six collapse into two prescription wedges; three are independent items. Gap 9 surfaced during this initiative's Stage 3 portal work — the rally-hq leakage you may have noticed in this portal's first render is the evidence.

#
Gap
Named pattern that closes it
Lands in
1
Filesystem-coupled distribution. Methodology lives at `~/Workspace/dev/wip/blueprint/` — breaks for anyone who doesn't mirror the path.
`npx init` — universal across CRA, Vite, Yeoman, Cookiecutter, Backstage. ai-hive's Mode A is the runtime-substrate equivalent.
Distribution wedge
2
No versioning. No semver, no changelog beyond git log, no migration guides between methodology revisions.
Semver + conventional-commit-driven changelog. Consumer pins `methodology_version` in blueprint.yml; SessionStart hook checks compatibility.
Distribution wedge
3
Discoverability is "Nino tells someone about it." No marketing surface, no hosted docs, no example gallery.
Hosted reference deploy that demonstrates the tool on itself — ai-hive's `ai-hive-mcp.example-account.workers.dev` pattern.
Self-applying portal
4
Reviewers are Claude-Code-locked. Markdown specs invoked by Agent tool; non-Claude consumers + CI workflows have no path.
Lopopolo's "custom linters with remediation injection." Executable .mjs paired with markdown specs; invokable from CLI + MCP + GitHub Actions.
Portability wedge
5
No tests on stamper or reviewers. One smoke test on the stamper; reviewers verified by reading them.
Contract tests per reviewer (passing fixture + per-failure-mode fixtures) + integration tests on the stamper. CI runs the suite on every methodology-repo PR.
Contract tests in CI
6
No telemetry / feedback loop. Methodology evolves only via Nino's direct observation. The 2026-05-25 reconciliation was caught manually.
Lopopolo's "doc-gardening agent" — recurring background task scanning for drift between docs, reviewer specs, and stamper behavior; opens fix-up PRs.
Gardening agent
7
Onboarding is "paste the right prompt." Methodology hides behind a UX cliff — operators have to know which paste-prompt to use.
Interactive CLI flow replaces paste-prompt. `npx @blueprint/cli init` walks the variant + tier + pattern decisions inline.
Distribution wedge
8
No integration surface. Blueprint doesn't talk to Linear/Jira/Slack/PR-comments. Artifacts are durable; workflow integration isn't.
GitHub Actions runner that invokes the conformance reviewers on every PR — closes half of Gap 8 + connects to Gap 4's portability wedge.
Portability wedge (partial)
9
Pattern B template is rally-hq with placeholders. The methodology repo's template/portal/ is rally-hq's portal copy-pasted with three placeholder strings. Lane cards, chat system prompt, doc taxonomy, navigation hrefs, CSS variable names — all rally-hq specifics carried verbatim into "the template." Discovered late on 2026-05-25 during this initiative's Stage 3 portal work.
Mechanically-checkable Pattern B stamper. Substitution surface wider than the L5 deferral named — must cover lane cards, chat backend, doc index, nav hrefs, CSS variable names. template/portal/ regenerates as generic substrate before the stamper can work.
